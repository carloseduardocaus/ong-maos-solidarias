# 🤝 ONG Mãos Solidárias — Single Page Application (SPA)

> Aplicação web dinâmica, modular e acessível concebida para a organização **Mãos Solidárias**.

[![WCAG 2.1 AA](https://img.shields.io/badge/WCAG-2.1%20AA-green.svg)](https://www.w3.org/WAI/standards-guidelines/wcag/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Version](https://img.shields.io/badge/version-1.0.0-brightgreen.svg)](https://semver.org)

## 📌 Visão Geral
SPA construída em Vanilla JavaScript orientada aos padrões modernos da web, assegurando alta performance, navegação instantânea por hash e total conformidade com diretrizes de acessibilidade internacional (WCAG 2.1 AA).

## 🚀 Tecnologias
- **HTML5:** Landmarks estruturais (`header`, `nav`, `main`, `footer`) e marcação semântica.
- **CSS3:** Sistema de tokens e variáveis em `:root`, Grid, Flexbox e modo de Alto Contraste.
- **Vanilla JS (ES6+):** Arquitetura orientada a módulos (`import`/`export`), roteamento SPA (`hashchange`) e Web Storage API (`localStorage`).
- **SweetAlert2:** Notificações modais acessíveis.
